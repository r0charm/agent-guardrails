# Security

Report a vulnerability privately through GitHub: the repo's **Security** tab, **Report a vulnerability**. Please do not open a public issue for it.

A command that runs destructively and passes every guard silently is a gap, not a vulnerability: open an issue, or add it to `guards/known-leaks`. A vulnerability is the guard itself doing harm, such as running part of a command or hanging the harness.

Only the latest version gets fixes.
